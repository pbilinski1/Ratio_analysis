# Industry Ratio Explorer

Ready for GitHub Pages.

## Upload
1. Create or open a GitHub repository.
2. Choose **Add file → Upload files**.
3. Drag `index.html`, `.nojekyll`, and `README.md` from this folder into the repository root.
4. Commit the files.
5. In **Settings → Pages**, choose **Deploy from a branch**, select your main branch and `/ (root)`, then save.

The website is self-contained: the workbook-derived data and chart code are embedded in `index.html`, so no build step is required.
